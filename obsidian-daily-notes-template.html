Obsidian Daily Notes Template (Free Printable): 6 Sections + a Weekly Review

A daily note only works if the page asks the same questions every day, and this free printable gives you the structure twice: once as paper, once as a pattern to copy. This daily notes template is a two-page set. Page one is a structure table with 6 rows, and each row names a section, what the section is for, and a write-in example. Page two holds the two boxes that keep a daily note alive past week one: a weekly review box with 4 lines and a tag-bank box with 4 lines, plus 4 opinion tips. The same 6 sections work typed into a note app or written on the printed page; the paper version just removes the tab-switching. The folder system this structure belongs to is mapped in the second brain vault guide, and the review habit it feeds is in the setup checklist.

How to use this page: print both pages at 100% scale, or copy the 6 sections into a fresh note and keep the order. One note per day, dated. Fill the sections in order the first week, then keep only the rows you actually use, because a row you skip three days running is a row to delete, not a row to feel guilty about. Page two is not daily: the review box gets filled once a week, and the tag bank grows only when a new type of note shows up.

The Close, in full. Three checks take two minutes: One thing done, or moved to tomorrow with a reason written down. Tomorrow's one thing already on the page. Anything urgent in Capture filed where it belongs, everything else left for the weekly pass.

Weekly review and tag bank - page 2 of 2

The review runs once a week, same sitting each time. Twenty rough minutes beat a perfect one that keeps waiting. (Opinion.)

Weekly review

1.Inbox to zero: every captured line sorted or deleted — lines left: ____
2.Projects: every active one has a next action written — dead ones archived: ____
3.Areas: one log line each (health, money, learning) — missing: ____________
4.Next week's one big thing + the calendar block it needs: ____________

Four lines is the whole review. If a line keeps coming back empty for a month, shrink it or cut it; the review exists to serve the notes, not the other way around. (Opinion.)

4 habits, all opinions

  1. One tag per note, and tags mark type, not topic. (Opinion.) Topics get links; types get tags. The moment a tag starts naming subjects, every note gains three of them and search returns noise. Six type tags cover a working vault.
  2. Write the daily note at the same anchor points, not on a schedule. (Opinion.) After the morning coffee and during the two-minute Close beat any calendar reminder, because anchors happen even on the days the schedule does not.
  3. Keep the note ugly during the day. (Opinion.) Paste the link now, format it never. A daily note that looks presentable is usually a note that took twenty minutes instead of two, and the twenty minutes came out of the One thing.
  4. Let the weekly review retire sections. (Opinion.) Once a month, read four old notes and delete whatever rows you never filled. The template that survives is the one you actually write, and a smaller one gets written more often.
