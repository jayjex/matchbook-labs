How to use this page: print both pages at 100% scale (the site chrome drops out on paper). Page 1 is the log: one row per container, filled in as things arrive and again the day one gets opened. Page 2 is the maintenance: the restock table holds the counts, and the expiry check runs whenever you sit down to do one. Print a fresh set when the twelve rows fill up; page 2 can be reprinted on its own.

The two-page lab inventory template

The columns on page 1 are inventory fields only: name, lot, received date, opened date, use-by. Nothing on the sheet tells anyone how to store or handle anything; your lab keeps its own rules, and a tracking sheet is not the place for them. The dates are the whole point of the row. The received date comes off the delivery paperwork, the opened date only exists if someone writes it that day, and the use-by is whatever is printed on the container. When all three sit in the same row, the question "what do we still have and how old is it" takes one look instead of a shelf search.

Page 2: the restock table and the expiry check

The restock table holds six rows because that is enough for the items that actually run out: one line per item, the count today, the count that means "order more", and the date the order went in. The expiry check below it is a fixed list of steps, the same every time, so the check depends on the page and not on whoever remembers to do it. Tick the boxes as you go, write the flagged row numbers on the notes lines, and set the next check date before you file the sheet away.

Four opinions on keeping a reagent tracking sheet

Opinions from keeping sheets like this, take or leave:

  1. Run the stock first-in, first-out. (Opinion.) New arrivals go behind the older rows on the same shelf, so the oldest lot is the next one out and the use-by column reads in the order you reach for things. When newer stock ends up in front, the old rows quietly age out at the back of the shelf.
  2. Write the opened date the day you open. (Opinion.) The received date survives on the delivery paperwork; the opened date survives nowhere except the moment it happens. A row with a backfilled opened date is a guess wearing a date.
  3. Make the storage codes boring and fixed. (Opinion.) A code that means one shelf forever beats a code that means different shelves in different months. The four-line box on page 1 is the legend: if a code is not on it, the code does not exist yet.
  4. Put the expiry check on a fixed day. (Opinion.) First Monday of the month, or whenever the binder gets touched anyway. A check that happens when someone remembers is a check that happens twice a year, and the notes lines are what make the fixed date cheap: the flagged rows are already written down.
