A crypto wallet hygiene checklist is a sheet of habits written in pen. Wallets, exchange logins and wallet apps drift: an app you stopped opening, a login you have not tested since spring, a venue you would not recognize by name next quarter. This printable page holds the cleanup - ten write-in hygiene rows with a date-done column and a Y/N circle, an alias map with three lines for the names you call accounts, and a printed box of three security rules. It is paper for organizing what you already have. Below the sheet sits a $16 checklist with a different target: 126 checks for reviewing smart-contract code.

How to use this page: print at 100% scale - everything fits on one sheet. Write one hygiene item per row: aliases you have named, backups that exist somewhere you can find, apps you no longer open. Put a date in the date-done column and circle Y or N only after you have actually looked. The alias map takes names only - recovery phrases and passwords have no place on paper. The three security rules at the bottom of the sheet are printed, so you can reread them each time the page comes out of the drawer.

Security rules - printed on every copy

  1. Never share a seed phrase or recovery phrase with anyone. Support staff never ask for one.
  2. Verify the address bar before signing in to an exchange or connecting a wallet.
  3. Send a small test transaction before a larger one to a new address.

4 opinions on running this hygiene pass

  1. One alias per exchange. (Opinion.) Pick one name format - venue, then your word for it - and use it everywhere the account appears: the sheet, the app's account label, the email folder. One alias per exchange means the row, the login and the withdrawal list all point at each other without a lookup. Several names for the same venue is how a record turns into a puzzle.
  2. Fill the rows from a list, not from memory. (Opinion.) Your phone's app list and browser bookmarks are the inventory; memory gives you the three you like. Walking the list row by row surfaces the wallet app you stopped opening months ago, which is the row this sheet exists for.
  3. Circle Done the same day you check the item. (Opinion.) A row with a date and no circle means the check got interrupted - fine for a day, less fine by next quarter. If the circle column is the slow one, do all ten circles in one sitting before writing any notes; a half-filled circle column reads as a finished column from across the desk.
  4. Reprint fresh each quarter and keep the old sheets. (Opinion.) Editing one sheet forever turns the checklist into a diary. A fresh print with the old sheet filed beside it shows what moved: which alias got renamed, which row finally got its circle, whether the same app shows up uncircled twice in a row.
