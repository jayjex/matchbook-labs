The one-page bujo weekly spread

Bullet journal habit trackers run horizontal for a reason we care about: the day reads as one column. Write the month on the line at the top and the weekday or date above each of the seven columns, then write up to six habits on the rows, phrased so a stranger could judge them ("walk 20 minutes" instead of "move more"). Each cell holds one small circle. Each evening, run your finger down today's column and mark it. At the end of the week, the finished page shows all seven columns side by side.

4 opinions on running the spread

Our opinions from keeping these pages, no research behind them, take or leave:

  1. (Opinion.) Cap the list at six. The sheet stops at six rows on purpose. Past six, the end-of-day column scan turns into a hunt, and a grid you stop scanning stops getting filled. Start with three, add a row only when a full week passes with every existing row marked.
  2. (Opinion.) Slash partials the same day, dot skips the same day. The key works only if an empty circle keeps one meaning: the day had not arrived or the page went unmarked. Mark each cell before you close the notebook, so an empty circle at week's end is a finding, not a shrug.
  3. (Opinion.) Read the spread down, never across. The horizontal layout pays off at review time: one column is one day, so the end-of-day pass takes seconds. If you find yourself filling the whole week in one sitting, the page has become a retrospective diary, and the day-by-day record it exists for is gone.
  4. (Opinion.) Tally before you start the next week. On the day you print a fresh page, count filled and slashed circles per row on the finished one and write the two numbers at the top of the new page. The counts, week over week, are the actual record; the circles are only how the counts got made.
