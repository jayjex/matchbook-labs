Remote Job Search Tracker (2-Page Printable)

Page one is a 12-row log for remote applications: company, role, date, a stage circle for where things stand, and a follow-up date. Page two rolls the rows up: a pipeline count by stage, a weekly goal you set yourself, four opinion tips, and a small interview-prep box. Print both pages, or copy the tables into a spreadsheet; the columns map one to one.

The stages: applied, screen, interview, offer

Each log row has four circles. Circle the one matching the stage the application is in right now:

AppliedSent. No reply yet.
ScreenA recruiter or hiring-manager call is booked or done.
InterviewLive rounds beyond the screen: team, technical, or final.
OfferTerms are on the table. The row stops here; accepting is outside this tracker.

When an application moves, cross out the old circle and mark the new one. One circle per row, the current state, not the history.

Four opinion tips

These are opinions from running my own hunts this way, not rules.

  1. Follow up once, then leave the row alone. One polite nudge after the follow-up date. A second and third message rarely pull a reply forward, and the time goes further into the next application.
  2. Set the follow-up date when you apply, not when you remember. Same day, while the posting is still open in a tab. A date written later is a guess; one written now is a plan.
  3. Filter remote postings twice. Once on the words "remote", once on the location line. Some listings say remote and then name a timezone or a country in the small print. Thirty seconds of checking beats a wasted row.
  4. Count weekly, decide monthly. Weekly counts move too much to steer by. Four or five of them in a row show a pattern worth acting on: where rows stall, and which stage needs volume.
