Deep Work Schedule Template — Free Printable One-Page Focus Blocks

Free

A focus block is a stretch of time assigned to one task before the day starts, with the phone out of reach. This deep work schedule template is one printable page that sets up to eight of those blocks: write the block time, write the single task the block is for, circle whether the phone was away, circle whether the task got done. A shutdown line closes the schedule, and a three-line box catches the distractions that showed up mid-block. The sheet records the plan and the circles; the work still has to happen, and the page only organizes it.

Two sibling sheets cover neighboring angles: the daily focus planner printable runs one full day per page with top-3 priorities and an energy log, and the time blocking template adds a week overview and an interruption log. Use this page when the day is already claimed and needs a schedule, not a diary.

Block time is yours to define: 9:00-10:30, "morning", "after lunch". The circles wait for the moment they describe: phone-away gets circled when the block starts, done gets circled when the task ends. Ctrl+P (or Cmd+P) prints the page.

Shutdown

Shutdown. Work stops at

One line, written before block 1. When shutdown time arrives, the empty rows stay empty and become tomorrow's first candidates.

Distractions

Three lines for whatever pulled at a block: a notification, a wandering errand, a half-remembered chore. Write the blocker down here, deal with it after shutdown.

4 opinion tips for a deep work schedule

Opinions, labeled as such. These held up for us; take or leave:

  1. Two blocks beats six. (Opinion.) The eight-row table is a menu, not a quota. Two 90-minute blocks that run beat six half-hour slots that collapse at the first interruption. Fill the rows you will defend, leave the rest blank.
  2. One task per block, written as a noun. (Opinion.) "Billing" fills a block with anything; "send invoice #214" ends it. The write-in line is narrow on purpose.
  3. Circle phone-away before the block, not after. (Opinion.) Deciding where the phone sits is a scheduling decision, same as the times. Circles filled at the end of the day turn the sheet into a diary.
  4. Write the shutdown line first. (Opinion.) A schedule with no end fills every gap it has. Setting the shutdown time before block 1 makes the last block a deadline instead of a drift.

What this page is

A work-organization sheet. It lays out when blocks run, what each block is for, where the phone sits, and when the day shuts down. It predicts nothing: there is no claim here about productivity, career outcomes, or attention span, and the sheet does not measure ability. It records what you planned and what you circled.
