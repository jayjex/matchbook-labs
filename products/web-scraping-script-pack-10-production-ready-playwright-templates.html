10 self-contained Playwright scripts for Node 18+. Each file runs alone with --flags, no config files needed. The pack covers: paginated table to CSV, infinite scroll collector with dedupe, login once then reuse the session via storageState, price monitor that posts Slack or Discord alerts on change, CSV bulk form submitter, job board scraper with cross-run dedupe, sitemap crawler honoring robots.txt and crawl-delay, screenshot diff bot with sha256 change detection, API poller appending JSONL, and a retry fetch wrapper with exponential backoff and user agent rotation.

The details

All 10 scripts pass a 15-check smoke test against a local fixture site before packaging. Selectors sit in one EDIT block per file. Delays of 800 to 2500ms are built in and the crawler adopts the stricter delay when a site publishes crawl-delay. No captcha solving, no credential stuffing, no access-control evasion. Read the site ToS and robots.txt before pointing these at a site you do not own.
