Icon Design Consistency Guide — Free Checklist for a Consistent Icon Set

Free

An inconsistent icon set is a pile of small decisions nobody made. One icon got a 1.5 pixel stroke and the next got 2, one corner is rounded while its neighbor is square, one shape fills its box while another floats in it, and the toolbar reads as a collage. Consistent icon set design is mostly boring: lock five values before you draw, then check them after. This page lists the five rules, a six-point audit you can run in ten minutes, and four opinions marked as opinions. It is generic design knowledge, so it applies whether your icons are yours, ours, or from anywhere.

Five consistency rules

These five values decide whether a set reads as one set. None of them is a standard with one correct number; the rule is picking a value once and keeping it.

RuleWhat to lockWhat breaks without it
Stroke widthOne weight across the whole set. On a 24px grid, a 2px stroke is the common default.Icons at the same size read as different thicknesses, so the set looks like it came from two people.
Corner radiusOne radius value for every rounded corner, including the inside corners of curves.Some icons look soft and others look sharp, and the eye catches the difference before anyone can name it.
Grid sizeDraw every icon on the same grid. 16, 20, 24 and 32px are the common grids for UI work.Proportions drift: one icon crowds its box, another leaves dead space in the same box.
PaddingKeep the same clear space between the shape and the edge of the bounding box.A full-bleed icon next to a padded one looks bigger even when both are exactly 24px.
Color countCap the palette for the set, then cap it again per icon. One accent color per group is the usual pattern.Color per icon turns a row into a jumble and hides the group structure you built.

Write the five values down once, in one place, before drawing icon one. A rule that lives in your head is not locked.

Four opinions on testing icon sets

These are opinions, not rules. They match how the example pack was built, and they have survived contact with real toolbars.

  1. Test at 16px first. If a shape reads at 16 pixels, it will read at 24 and 32. The reverse is not true, and by the time you notice at the small size, the geometry is already drawn. (opinion)
  2. Fewer colors age better. A set with one accent per group stays coherent through additions; a per-icon palette falls apart somewhere around icon twelve. (opinion)
  3. Fixed sets beat sprawling ones for small teams. Fifty icons with enforced rules ship sooner and stay more consistent than five hundred loose ones, because there is less surface for the drift described above. (opinion)
  4. Re-run the audit after every addition. Consistency erodes in batches, not all at once. The checklist takes ten minutes and catches the drift while it is still cheap to fix. (opinion)
