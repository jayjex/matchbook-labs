NFL Stats Database Download: 7,548 Games, 46 Columns, One Flat CSV

This pack is for the person who wants to build the model or the spreadsheet themselves. It ships as flat CSV files that load into Excel, Google Sheets, pandas, or R without cleanup: 7,548 NFL games from 1999 through the 2026 schedule with 46 columns each, 861 team-season rows, and 27 season summaries. The files hold the data and the join keys. You build your own views on top.

What's in the download

  • games.csv - 7,548 rows, one per game, 1999 through the 2026 schedule, 46 columns. Final scores, gameday, teams, rest days, starting QBs, coaches, referee, stadium, roof, surface, temperature, and wind, plus the market columns recorded per game where tracked (closing spread, total, moneylines). Every column is defined in the dictionary, so nothing in the file is a guess.
  • team-records-by-season.csv - 861 team-season rows: W/L/T, points for and against, ATS wins/losses/pushes, ATS win percentage, and over/under records, straight back to 1999.
  • season-summaries.csv - 27 rows, one per season from 1999 through 2025. League-level averages, home win percentage, favorite and underdog cover rates, and over/under splits.
  • data-dictionary.md - every column defined, including which years each field starts.

Want to check the file shape first? The free NFL data sample has 100 games with the same 46 columns, so the download you test is the download you get.

Flat CSV, on purpose

Each file is one table with one row per record. No merged cells, no summary tabs doing the aggregation for you, and no pivots pre-baked. The structure is deliberately boring because boring loads fast and joins cleanly:

  • game_id (like 2025_01_KC_LAC) identifies every game row, so anything you derive per game joins back to games.csv on one column.
  • team plus season key the team-season file, so a team's yearly records merge against any slice of the games file you cut.
  • season alone keys season-summaries.csv when you want the league-level numbers next to your own per-season aggregates.

If you want an average, group by the column. If you want a team's game log, filter by the team. The pack stays out of the way of your model's shape.

Checksums: your copy matches the built copy

Every bundle ships with SHA256SUMS.txt, one SHA-256 hash per component zip. Run sha256sum -c SHA256SUMS.txt after download; if it prints OK on all four lines, the files on your disk are byte-identical to what was built. For a dataset feeding a model, the check matters because a truncated download produces rows that look fine until a season total comes up short. The checksum turns that silent failure into a printed FAIL.

Three things analysts do with it

Spreadsheet modeling

Load games.csv into Excel or Sheets, add your own columns, and build per-team or per-season tables with formulas and a pivot you control. Because the columns stay flat, every formula references a plain cell range and nothing breaks when you sort.

Stat research

Rest days against scoring, home win percentage before and after 2020, scoring by roof type, week-by-week totals across an era. These are descriptive questions, and the columns that answer them sit on the same row as the score.

League-history lookups

Twenty-seven season summaries in one table: league scoring averages per year, home win rates per year, how often favorites covered per era. Pull one season or compare three decades without writing a scraper.

The pack records what happened and where lines closed. It doesn't tell anyone what to bet, promises nothing about future games, and nothing on this page is betting advice.

Field coverage, honestly

  • Which fields start when. Spreads and totals run 1999 onward; moneylines and the American odds fields start in 2006. Some 1990s rows miss the field entirely rather than showing a zero.
  • One snapshot per game, not a movement log. Each line field holds a single closing value taken when the dataset was built. If your model needs intraweek movement, you need a second source.
  • The 2026 season is scheduled, not played. Those rows carry games and, where posted, lines; scores stay empty until each game is played.
