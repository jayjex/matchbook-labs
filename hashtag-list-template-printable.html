Why write the bank down at all

Tags retyped from memory drift. A spelling slips, a word order flips, and the list you thought you were reusing is now three near-duplicates. The bank table fixes the list once: fifteen slots per tier, filled in ink, sitting where you can check them before you paste. It also gives you a place to notice a tag you stopped using, which is invisible when the list lives in a notes app you scroll past.

The three tiers: broad, mid, niche

The split is descriptive, not a rule from anywhere. Broad holds the big general tags that fit almost any post on your topic, the ones everyone in the field types. Mid holds tags with your subject in them: the craft, the tool, the category. Niche holds the small exact tags for the specific community or sub-topic the post belongs to. Each row gets its own write-in topic line so you can keep more than one list on one sheet: one set of tiers for a product, another for a hobby. Fifteen is a slot count, not advice about how many to post; fill what you actually use and leave the rest empty.

Four rotation habits

Opinions from keeping tag lists like this one, take or leave:

  1. Rotate sets weekly. Opinion: a weekly swap gives each set a scheduled review. Every seven days you rewrite one page of tags, which is when stale entries and typos get caught, and no single set becomes the one you paste forever without reading.
  2. Rebuild the niche row first. Opinion: small exact tags track your current work, and current work moves faster than your field's general vocabulary. When a set goes stale, it usually goes stale bottom-up.
  3. Keep the banned line filled. Opinion: writing down the tags you have decided against stops them coming back on a fast typing day. A rule you can see survives; a rule in your head gets re-litigated every week.
  4. Copy the set once, paste it whole. Opinion: retyping fifteen tags by hand is how spelling drift starts. One clean copy-paste from the bank keeps every post's list identical to the page.

What this page does not do

It organizes tags; it predicts nothing. There is no claim here about how any platform ranks, distributes, or limits posts, no follower numbers, and no promise that a filled sheet does anything for a post's performance. Those are platform-side systems the sheet never touches. What it does is put your tag list on two pages you can print, check, and rotate, so the mechanical part of posting is written down.
