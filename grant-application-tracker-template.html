Grant Application Tracker — Free Printable 2-Page Template

Free

Grant applications pile up the moment you apply to more than one program. Which one wanted the budget by Friday? Which one has been sitting in review since March? This template keeps the answers on paper. Page 1 is a log of every application you send, with a status you circle by hand. Page 2 holds deadlines, the materials each program asks for, and a notes box. It works the same for a solo developer applying to ecosystem grants and for a research organization running several proposals at once.

Generic list, so it covers most research and ecosystem programs. Some ask for less, some for more. The program's own page outranks this sheet.

Notes

4 opinion tips for grant tracking

Opinions, labeled as such. These are habits that held up for us, not rules:

  1. Track rejections too. (Opinion.) A rejected application with reviewer comments attached is research for the next one. If your log only records wins, it hides the part you learn from.
  2. Write the follow-up date when you submit. (Opinion.) Same day, while the program name is still in your head. A follow-up column full of blanks is a log; one with dates is a schedule.
  3. Fewer applications, done properly. (Opinion.) Ten rushed applications to programs you haven't read lose to three tailored ones with the requirements checked off.
  4. Reuse answers, re-read questions. (Opinion.) The summary you wrote for one program is a good first draft for the next, but programs ask different things under similar headings. Paste, then edit.
