Desk Setup Checklist Printable (Free, One Page)

A desk drifts. Things land on it, stay a week, and become furniture. This page gives the drift one page to fight: a printable checklist with 12 write-in rows grouped into three zones (screen, paper, cable and misc), each row ending in a done circle, plus a weekly reset box. Write what belongs in each zone, then circle done when the zone is actually clear. Print free, one page, no software.

How it works: one row per thing that lives on the desk. Write the item in its zone, clear the zone, circle done. Twelve rows fit a one-page print at 100% scale. The sheet tracks where things sit and nothing else.

Four opinions from resetting desks

  1. (Opinion.) One screen is the right starting number. A second monitor mostly adds surfaces to watch and cables to route. Fill all twelve rows on one screen and one sheet of paper first; add hardware only when a real task keeps failing for lack of it.
  2. (Opinion.) Empty surface beats storage system. If an item has no row on the sheet, it does not live on the desk. Boxes and organizers hide the drift; a row per item makes it visible.
  3. (Opinion.) Circle done only when the zone is actually clear. A row with three items half-shoved into a drawer is not done. The circle is a small lie that costs you the whole sheet.
  4. (Opinion.) Tape the sheet where you look, not where it looks tidy. The kit below is described in its own README as "designed to be glanced at, not read". Eye line next to the monitor wins over a folder of printouts nobody opens.
