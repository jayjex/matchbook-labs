This one fits on a single printed sheet: a date line, three must-do slots, an 8-row time-block table where you write your own start times, a park-lot for the distractions that show up uninvited, and a three-question wrap-up before you stop for the day. No app, no login, nothing to charge. Print it, work it, bin it or keep it. If you want the whole week on one sheet instead of one day, that is the paper daily planner page.

How to use this page: hit print, write today's date, and fill the top-3 slots before opening anything else. Each time block gets a start time you choose and one task; the done box gets ticked only when the task is done, not when the block ends. The park-lot takes anything that pulls at you mid-task. The sections sit in this order on purpose. Must-do comes before the time table because a plan that starts with the clock ends up scheduling whatever shouted loudest. The start column stays empty on purpose too: eight equal rows say nothing about how long your work takes in practice, and yesterday's page is the only honest source for that. The park-lot is four lines because most days need fewer. The wrap-up is three questions because a debrief you skip by Tuesday was never going to survive five.

Four tips for running the page

Opinions, not science - these come from printing and burying plenty of these pages, and your mileage will differ.

  1. Hardest task first. The top-3 list works best when slot 1 is the thing you have been rehearsing ways to avoid. Easier tasks shrink to fit whatever time is left; hard ones only grow. If the hard thing is still untouched by noon, the park-lot will show you what has been eating the morning.
  2. One block, one job. Write a task per row, not a theme per row. "Draft the invoice email" gets done; "admin work" absorbs the whole morning and produces a paragraph of nothing. Leave the phone in another room while a block runs.
  3. Park the distraction, don't chase it. Mid-task, the sudden urge to look up a price, reply to a text, or reorganize a folder goes on one park-lot line, then the block continues. Most parked items look ignorable by 17:00; the ones that don't get a row tomorrow. Chasing them now is how a two-minute errand eats a block.
  4. Write tomorrow's first task before closing. The last wrap-up line asks for tomorrow's first task for a reason: morning-you starts reading instead of deciding, and deciding is where the morning usually goes. It takes twenty seconds tonight.

One day per page, or a week per page?

Both versions print on one sheet, and they answer different questions. This daily focus page goes deep: timed work blocks with your own start times, a park-lot, and an end-of-day debrief, which suits days with real work to push - a build, a launch, a deadline. The paper daily planner runs wide instead: one sheet covers the whole week with habit checkboxes and a weekly review, which suits keeping the week honest when no single day is heavy. Plenty of setups use both - the weekly sheet pinned over the desk, one daily sheet printed on the days that matter.
