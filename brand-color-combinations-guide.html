How the three roles pair

The same three roles sit behind every palette above. Assign them in this order and most combinations hold together.

RoleWhat it doesWorking rule
BackgroundCovers most of the surface and sets the mood.Pick it first. Text sits on top of it everywhere, so a background that fights readability poisons every other choice.
TextCarries everything the visitor reads.The highest-contrast pair in the palette. Dark backgrounds take near-white text; light backgrounds take near-black. Each pair in the table above clears that bar.
AccentMarks links, buttons, prices, and the logo itself.Use it on the fewest elements you can. An accent on ten things is an accent on nothing.

Readability: the one mechanics note

Body text needs a strong difference from its background, and the common benchmark is a contrast ratio of about 4.5:1 or higher (the WCAG AA level for normal text). Accents play a different job: they work fine for buttons, links, and short labels, but a mid-tone accent color makes tiring body copy, so keep paragraphs in the text role. Contrast values from memory are guesses, so check the final pair on an actual phone and an actual laptop before shipping.

Four opinions on picking brand colors

These are opinions, not rules. Each one is labeled as such, and each has saved time on real projects.

  1. Start with two colors. (opinion) Background plus text is a working brand palette; the accent is a bonus, and it comes last. Brands that pick the accent first usually end up rebuilding the other two around it.
  2. Steal the accent from an asset you already have. (opinion) If a logo or product mark already owns a color, that color is the accent. Pulling it from the mark ties the palette to the brand for free.
  3. Soften both ends on dark palettes. (opinion) Pure white text on pure black background can look harsh and halo on some screens. Off-white on near-black, like Ledger Navy above, reads calmer at the same contrast.
  4. Write the hex codes down in one place. (opinion) Palettes drift when each page picks colors from memory. One list of three hex codes, copied everywhere, keeps page 40 matching page 1.
