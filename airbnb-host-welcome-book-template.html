Host Welcome Book Template (Printable, 2 Pages)

Guests ask four things in the first hour: the wifi, the door, the rules, the checkout. This free host welcome book template answers all four on page 1, and puts your local tips, emergency numbers, and trash day on page 2. Fill it in per stay, print it, and leave it where guests land. When two pages stop covering the property, the 22-page host binder picks up the rest.

How to use this page: print both pages at 100% scale (the site chrome drops out on paper). Page 1 is guest-facing: fill in the letter, wifi and access, house rules, and checkout list before each stay. Page 2 holds your local recs and numbers; it changes more often, so keep it as the loose sheet. Photocopy per stay or reprint whichever page changed.

Page 1: the first-hour questions

Nothing on page 1 is pre-filled. Door codes rotate, wifi passwords get changed, and rules get rewritten after one rough weekend; a stale sheet sends guests to their phones with questions. The letter skeleton gives guests a greeting in your voice in four lines, the wifi and access box carries the facts, the house rules run as six checkbox lines that scan in seconds, and checkout becomes five boxes instead of a paragraph.

Four opinions from filling these in

Opinions from running sheets like this, take or leave:

  1. Laminate page 1, keep page 2 loose. (Opinion.) The laminated sheet survives spills and a season of stays. The local page changes whenever a place closes or a code rotates, so it stays reprintable.
  2. One sheet per stay, dated. (Opinion.) Codes and passwords rotate. A date in the corner tells you which copy is current, and the old copy leaves with the trash.
  3. Leave it where guests land. (Opinion.) Kitchen counter, key tray, next to the coffee maker. Nobody opens a drawer on arrival.
  4. Write the recs like a text to a friend. (Opinion.) One honest line about the taco place beats a row of brochures, and guests can tell the difference. If a spot paid you nothing and you would still send your sister, it belongs on the table.
