Twelve rows, one per variety or per tray. Write the seed name the way the packet says it, not the way you will remember it later; both go in the notes column if they differ. Transplant table (page 2)

Six rows for the seedlings that move out of trays. Copy the seed name from page 1, write the sprout date it already has, then log the day it gets planted out and where it went. The pair of dates is the point: next round, the gap between them tells you how long a tray held that crop.

Four record-keeping opinions

  1. Label everything. (Opinion.) Trays without labels turn into a guessing game by week two, and the log can only tell you what you planted, not which tray is which. A marked spoon or a strip of tape on every tray, matched to the row number, keeps the sheet and the shelf telling the same story.
  2. Write the sprout date the day it happens. (Opinion.) The gap between sowing and sprouting is the number you will want next round, and it only exists if someone wrote it down on the day. A row with a blank sprout date is still a record; it records a seed that never got a follow-up.
  3. Keep the log inside the seed box. (Opinion.) A seed-starting sheet filed anywhere else stops getting filled in. Same box as the packets means the row gets written while the packet is still in your hand, and last round's day counts are right there at ordering time.
  4. Log the duds too. (Opinion.) A row for seed that never sprouted is the most useful row on the page come next season. The day count you circled on the winners and the blank where the duds sat are both data; the sheet works because it holds both without judging either.
