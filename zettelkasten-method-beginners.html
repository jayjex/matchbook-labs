Zettelkasten Method for Beginners: How to Start Free

A zettelkasten is a stack of notes that link to each other. The sociologist Niklas Luhmann ran one on about 90,000 index cards, and the method he used has been public for decades. It runs on paper, plain markdown files, or the notes app you already have, so you can start a zettelkasten free today. This page explains the three note types, gives you a 10-box starter checklist, and a 4-step daily loop. If you want the same method with the folder structure already built, we also maintain a second-brain Obsidian template and a second-brain setup checklist that cover the surrounding system.

The Method in Three Note Types

Everything in a zettelkasten falls into one of three buckets.

TypeWhat it isExample
Literature noteQuick notes taken while you read: quotes, page numbers, your shorthand. One file per source. Messy is fine, because these are raw material.books/habits-atomic.md with three quotes and a page reference
Permanent noteOne idea, written in your own words, in complete sentences. This is the unit the whole system runs on. If a note holds five ideas, it becomes five permanent notes."Decision fatigue shrinks as options get concrete" in 4 sentences
LinkA connection from one permanent note to another, with a word on why they are related. In markdown apps this is a [[wikilink]]; on paper it is a card number in the corner.Linked to checklists beat intentions "because both reduce in-the-moment choices"

Literature notes feed permanent notes, permanent notes link to each other. The links are where the payoff shows up: months in, you find connections between things you read a year apart.

How to Start a Zettelkasten Free: 10 Boxes in 3 Passes

Do these in order, one pass at a time. Nothing here needs a paid app or a plugin. Each box has a "done means" line so you know when to move on.

Pass 1, Capture (3 boxes)

  1. ☐Create one folder called Notes. No subfolders yet. Done means: the folder exists and is empty. Resist filling it with structure before any note exists.
  2. ☐Write one literature note from something you read this week. Quotes, page numbers, your shorthand, and the source at the bottom. Done means: one file exists, under a screen long, and a reader could find the source from what you wrote at the bottom.
  3. ☐Capture two more, from the same source or different ones. Done means: three literature notes exist. Messy counts. Perfection here is the most common place beginners quit.

Pass 2, Process (3 boxes)

  1. ☐Open your best capture and write one permanent note from it. One idea, your own words, 3 to 5 sentences, no bullet list. Done means: a new file exists that makes sense on its own, with the literature note's name mentioned somewhere inside it.
  2. ☐Do the same for the other two captures. One idea per note. If a capture holds two ideas, that is two permanent notes. Done means: three permanent notes exist, and each one is short enough to read in under 30 seconds.
  3. ☐Decide where literature notes live from now on. An inbox folder is fine; they are raw material, not the product. Done means: you can answer "where does a captured note go" without thinking. The literature notes from today are in that place.

Pass 3, Link (4 boxes)

  1. ☐Add a link from one permanent note to another. In Obsidian or any markdown app that is [[note name]]. On paper it is the card number. Done means: at least one of your three permanent notes names another one of them.
  2. ☐Write one sentence on why they are related. A link without a reason turns into an untended pile. Done means: the link has a sentence next to it that a stranger could read and get the connection.
  3. ☐Link today's notes from your index. A single file that lists your notes by topic works before any fancy structure does. Done means: the index file exists and lists all three permanent notes under a topic word you would actually search for.
  4. ☐Skim your three notes and ask what is missing. Usually one question comes up that a future note should answer. Write it at the bottom of a note as a prompt. Done means: one open question is written down somewhere in the system, which is what pulls you back tomorrow.

The Daily Loop, 4 Steps

Once the starter checklist is done, the whole habit is about 15 minutes a day:

  1. Capture (2 min): anything worth keeping from what you read becomes a literature note, one file per source.
  2. Make one permanent (5 min): pick the best capture of the day and write one permanent note in your own words. One, not ten.
  3. Link it (3 min): add links to one to three permanent notes it touches, each with a one-line reason.
  4. Index it (1 min): if the note starts a new topic, add a line to your index.

Day one of the loop is the day the zettelkasten starts compounding, because every new note scans the old ones for connections.

Four Opinions on Starting

  1. Small notes beat big ones. A note that holds five ideas can't be linked to one thing, so it never gets linked. One idea per note is the rule that makes everything else work.
  2. Link while you write, not afterward. The connection is obvious the second you think of it and gone a week later. Nobody ever does the backfill weekend.
  3. Your own words or it doesn't count. Copy-paste is collecting, and a collection of other people's sentences filed under your name will never surprise you. The permanent note is where you argue with the source.
  4. Let structure come last. Folder trees designed before the first ten notes get guessed wrong. Write the notes, then look at what they cluster around, then name the folders.

It Runs in Any App

Nothing above needs a specific tool. The method runs on index cards, plain markdown files, Notion, Apple Notes, Google Keep, Obsidian, or a stack of paper. The only features it leans on are a way to make a new note fast and a way to name another note from inside one. If your tool does those two things, it is a zettelkasten tool.
