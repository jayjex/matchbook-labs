The 12 Columns, Explained

  • id - Airbnb listing ID, stable across snapshots. Use it to join or dedupe.
  • name - the listing title, truncated to 80 characters. Host-written text, so expect marketing language.
  • neighbourhood - Inside Airbnb's cleansed neighbourhood name, drawn from open GIS boundaries rather than host input.
  • latitude / longitude - rounded to 4 decimal places, about 11 meters of precision. Deliberately blurred so no exact address can be recovered.
  • room_type - one of Entire home/apt, Private room, Hotel room, Shared room.
  • price - nightly list price in US dollars, cleaned from the source's "$1,234.00" text. The advertised rate, not the settled rate with fees.
  • minimum_nights - the shortest stay the listing accepts.
  • availability_365 - nights open in the next 365 days per the scrape-day calendar. A proxy for how active the calendar is, not realized occupancy.
  • number_of_reviews - lifetime review count at snapshot.
  • reviews_per_month - lifetime review rate, blank when the listing has zero reviews. Roughly half of guest stays leave reviews, so real demand runs higher than this column implies.
  • last_review - date of the most recent review, blank if never reviewed. Reviews lag, so a listing booked this month can still show an old date.

Same 12 columns in all six city files, so joins and group-bys work across cities in pandas, Sheets or R without schema surgery. ZIP-level rent benchmarks join onto the same geography: the HUD fair market rent data pack keys FMR by ZIP code and county for all 50 states.

No Host Data, On Purpose

The pack carries no host names, no host IDs, no host profile links and no exact street addresses. Coordinates are rounded to 4 decimal places and listing names are truncated. That keeps the analytic value (price levels, location patterns, room-type mix, calendar availability) and cuts the surveillance value.

For client work this matters in a boring, practical way: you can put these CSVs into a report, a model or a slide deck without handling personal data you'd have to safeguard. If you genuinely need host-level fields, the full-detail source files are on Inside Airbnb under the same CC BY 4.0 license.
