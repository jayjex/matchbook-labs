Weekly Metrics Review Template (Free Printable)

A two-page weekly metrics review template for a 15-minute KPI review meeting, same day every week. Page 1 is an eight-row table: the metric, its target, its actual, and a circle for whether it went up, stayed flat, or went down. Page 2 is where you write why the number moved and what next week gets. Print it, fill it by hand, file it. The numbers it reviews can come from anywhere, including the $10 KPI Sheets Pack linked at the bottom.

How to use this page: print both pages, pick your eight metrics once, and do not re-pick them weekly. Run the review the same day each week so last week's sheet is always one week old, never one month old. Fifteen minutes is enough. A metric that never gets reviewed is a metric you are collecting, not tracking.

Page 1: the metrics table

Eight rows is the cap, by design. Write the metric, the target you set for it, the actual number for the week, then circle the direction. The target is written by you: a number you chose on purpose beats a blank line you keep meaning to fill.

Four opinions, from running reviews

  • (Opinion.) Same day each week. A review that moves around the calendar becomes a review that quietly stops.
  • (Opinion.) Write the why while looking at last week's sheet, not from memory. Two weeks of sheets side by side beats any recollection.
  • (Opinion.) Flat is a result too. Circle it and move on; forcing a direction on an unchanged number is how review sheets start lying.
  • (Opinion.) Next-week actions go on three lines, not thirty. If the fix needs more than three lines, it is a project, and it needs its own sheet.

What this sheet is: a review sheet. It records what happened to numbers you chose, once a week, in writing. It is not a growth promise: numbers go down too, and filling the table does not make them go up. The table is honest on purpose, including the down circles.
